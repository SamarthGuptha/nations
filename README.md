# Nations the game!!!  
Hello and welcome to this turn based World Domination game, inspired by the board game "Risk".

# How does the game work?
- First head on over to the [sign up page](https://nations-58f78.web.app), then either Create a game and share the game code with your friends OR join a game with the code!
- Once the game loads, the first player MUST spin the wheel, they have 2 chances to build something, after which they can either choose to End their turn or attack another player.
- You can only attack player's lands adjacent to your own, first click the land you want to attack from, then click on another players land that is adjacent to yours! (this works on a weighted die roll)

# Behind the Scenes
- Works on a firebase backend via the use of RTDB Database
- Use of firebase's anonymous auth system
- Use of server side time stamps to keep track of connection.
- Vanilla HTML, CSS & JS

# Features
- Building infrastructure within your country's "Land".
- Attack other "Nations", or players.
- Drafting cards also known as "slices" to edit your own wheel(this happens once you've built something thrice)
